## Selected Works

<!-- PROJECT 1 -->
<details>
<summary><b>Hime Browser</b> &nbsp;·&nbsp; <i>A web browser engine. Built. From. Scratch.</i> &nbsp; <code>Python</code> <code>Skia</code> <code>SDL2</code> <code>OpenGL</code> <code>DukPy</code></summary>
<br>

> *Most developers use browsers. I built one.*

**Hime** is a fully functional web browser engine written entirely in Python — no Electron, no WebKit, no Chromium. Every layer of the stack was implemented manually, following the architecture taught in the [Web Browser Engineering](https://browser.engineering/) book.

**What's under the hood:**
- **Raw socket HTTP** — no `requests`, no `urllib`. Pure TCP.
- **Custom HTML/CSS parsers** — hand-rolled tokenizers and AST builders for the DOM & CSSOM
- **Full layout engine** — block/inline/anonymous boxes, font metrics, absolute positioning
- **GPU-accelerated rendering** — SDL2 windowing + Skia rasterizer over OpenGL
- **Multi-threaded pipeline** — display lists, compositing, async task scheduler
- **JavaScript runtime** — Duktape (via `dukpy`) for scripting support
- **Accessibility tree** — full a11y node generation for screen readers
- **Browser chrome** — tabs, address bar, scroll state, focus handling

**→ [kurogamidesuu/Hime-Browser](https://github.com/kurogamidesuu/Hime-Browser)**

</details>
